# Data Center AddOn 1.7.7

Part 8 of the new customer model: **segment pools**. Game server customers now come with the big multiplayer games, streaming customers with the video platforms.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar) · Jade 15 (for the look-at tooltips)
Install on the **server and every client**, in exactly the same version.

## Launches that grow a segment
Each launch raises its segment's pool **for good** and, for about a year, **a bit more (hype)** that fades by 63 % in 12 months.

| Segment | Launch | Lasting | Hype |
|---|---|---|---|
| Game servers | Counter-Strike beta (June 1999) | +5 % | +15 % |
| | Counter-Strike 1.0 (Nov 2000) | +15 % | +25 % |
| | Battlefield 1942 (Sep 2002) | +5 % | +15 % |
| | Counter-Strike: Source (Nov 2004) | +10 % | +20 % |
| | World of Warcraft (Nov 2004) | +10 % | +30 % |
| | Team Fortress 2, Call of Duty 4 (Oct/Nov 2007) | +5 % each | +15 % each |
| | Minecraft (Nov 2011) | +25 % | +40 % |
| | ARK (2017), Rust (2018) | +5 % each | +15 % each |
| | Valheim (Feb 2021) | +5 % | +30 % |
| | Palworld (Jan 2024) | +3 % | +25 % |
| Streaming | YouTube (Feb 2005) | +20 % | +30 % |
| | Netflix streaming (Jan 2007) | +20 % | +20 % |
| | Twitch (June 2011) | +20 % | +30 % |

- Data Center already starts game servers in June 1999 and streaming in February 2005. These launches come on top.
- A product's market grows by the boosts of its segments, weighted by how much of the product each segment buys. Game servers feel the games fully; VPS and colocation feel both a little (they have game and streaming customers too).
- New customers come in the boosted mix: after a big launch more of them are from that segment.
- Example: the game server market in 2009 is about 1,200 instead of 750; VPS about 2,950 instead of 2,650.
