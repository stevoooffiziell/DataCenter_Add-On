# Data Center AddOn 1.9.8

Part 9 of the add-on's industry: the **Hardware Fab**. It builds real server parts from your factory's components: any CPU, GPU, RAM module, drive, power supply, mainboard or fan that is on sale in the Shop today.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar) · Jade 15 (for the look-at tooltips)
Install on the **server and every client**, in exactly the same version.

## Hardware Fab
In the Shop (Infrastructure, $25,000). Magenta front.

### Choosing a part
- **Left side of the screen:** a tab per kind of part (CPU, GPU, RAM, storage, power supply, board, fan) and a list of every model of that kind on sale today, with its Shop price. Scroll with the mouse wheel.
- Click a model to build it, click it again to stop. Only parts that are on sale today can be chosen: release dates stay as they are, and parts hidden by the config or retired from the Shop are not offered.
- Every Data Center and add-on part counts: desktop and server CPUs, consumer, datacenter and mining GPUs, mining boards and so on.

### What a part needs
- Components worth **about half the part's current Shop price** (with the Shop's depreciation and shortages), valued at what the Sales Terminal pays for them at full demand.
- The mix depends on the kind of part:

| Kind | Microchips | Circuit boards | Capacitors | Connectors | Plastic parts | Copper wire |
|---|---|---|---|---|---|---|
| CPU | 60 % | 10 % | 10 % | 20 % | | |
| GPU | 40 % | 25 % | 15 % | 15 % | 5 % | |
| RAM | 60 % | 30 % | | 10 % | | |
| Storage | 25 % | 25 % | 15 % | | 20 % | 15 % |
| Power supply | | 20 % | 35 % | | 15 % | 30 % |
| Board | 10 % | 45 % | 20 % | 25 % | | |
| Fan | | 10 % | | | 60 % | 30 % |

- Example: a CPU with a Shop price of $300 needs about 8 microchips, 3 circuit boards, 10 capacitors and 5 connectors (≈ $160 of material).
- **Time:** 5 s plus 1 s per $400 of Shop price, at most 60 s per part. **Power:** 60 FE per tick, buffer 100,000 FE (up to 4,000 FE per tick in).
- The screen shows the chosen part, its material value and time, and every component it needs: green when the inputs hold enough, red when not.

### Slots and automation
- **9 input slots** for the components, **3 output slots** for finished parts. Hoppers and pipes fill the inputs and empty the outputs, from any side.
- A finished part is a normal, new part, the same as from the Shop.

### Sell-back
A built part carries the value of its components as the price paid for it. Data Center's Shop buys it back for at most 80 % of that, so the Hardware Fab cannot be used to sell parts above what their components are worth.

## Config
New option in the `industry` section:

| Option | Default | Meaning |
|---|---|---|
| `hardwareCost` | 1.0 | Components a part needs, as a multiple of half its Shop price (1.0 ≈ 50 %, 2.0 ≈ 100 %) |
