# Data Center AddOn 1.8.0

The start of a new reputation model, one piece per release in 1.8.x. Step 1: **running servers no longer earn reputation by the hour.** Reputation has to come from what you do, not from waiting.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar) · Jade 15 (for the look-at tooltips)
Install on the **server and every client**, in exactly the same version.

## No hourly gain
- Data Center gives **+0.05 reputation per serving server and game hour** (+25 % per certification tier of the room). With the reputation model on, this gain is gone, for hosting racks of every kind (shared, VPS, colocation, dedicated).
- **The deductions stay** as in Data Center:
  - throttled racks (heat, attack, slow network): −0.05 per server and game hour,
  - overloaded servers: −0.05 per overloaded server and game hour,
  - servers or customers that are down: −0.025 per server and game hour,
  - a crash: −20.
- Reputation you already have stays.
- Contracts and delivery orders still give reputation, as before. More sources come in the next releases.

## Config
New section `reputation` in `data_center_addon-common.toml`:

| Option | Default | Meaning |
|---|---|---|
| `reputationModel` | true | Use the add-on's reputation model. `false`: Data Center's own reputation |

## Technical
The add-on takes the Hosting Rack's two `recordService` calls. If a Data Center update changes them, Data Center's own reputation runs again. The game does not crash.
