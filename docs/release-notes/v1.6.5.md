# Data Center AddOn 1.6.5

A maintenance release: the code that came in with 1.5.x and 1.6.x has been reorganised. The game plays the same, worlds and configs stay as they are, and the in-game config screen now has proper names for all options.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar) · Jade 15 (for the look-at tooltips)
Install on the **server and every client**. Server and clients must run the same version.

## Config screen
The options added since 1.5.0 now have names and tooltips in English and German in the in-game config screen (Mods → Data Center AddOn → Config):
- `contracts`
- `contractPayMultiplier`
- `deliveries`
- the whole `startup` section

Before, these options showed their raw keys.

## Under the hood
- **Hosting Manager screen:** split from one class of 1,100 lines into a frame, one class per tab and shared drawing helpers. Layout and behaviour are unchanged.
- **Contracts and deliveries** now live in their own package. So does the **founding phase**: start bonus, grant and loan; milestones; service tickets; prepayment. Each has its own class.
- **The network data of the Hosting Manager** is now encoded record by record. The packet content is the same as in 1.6.4.
- **Duplicates merged:** money formatting, client names, and the lists of cables and switches on sale at a date.
- **Removed:** a translation key and a helper method that were no longer used.

Saved data keeps its names, so contracts, deliveries, loans, milestones and tickets carry over unchanged.

## Languages
English and German.
