# Data Center AddOn 1.8.1

Part 2 of the new reputation model: **running is the baseline, not a source.** A company that runs reliably loses nothing, but it does not gain anything by the hour either.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar) · Jade 15 (for the look-at tooltips)
Install on the **server and every client**, in exactly the same version.

## Runtime as the baseline
- A rack that serves its customers, even a full one, now changes the reputation by **exactly 0**.
- **Overload no longer drains reputation by the hour.** Before, every server running over its real capacity cost 0.05 points per game hour, even on a rack that never failed. Overload still costs you: overloaded customers pay less, complain and cancel more (1.7.5).
- **Real failures still cost:**
  - throttled racks (heat, attack, slow network): −0.05 per server and game hour,
  - servers or customers that are down: −0.025 per server and game hour,
  - a crash: −20.
