# Data Center AddOn 1.6.4

Contracts now count with their product in the Hosting Manager's overview. They use that product's places, so they belong there.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar) · Jade 15 (for the look-at tooltips)
Install on the **server and every client**.

## Contracts in the product table
The separate row **Contracts (n)** in the Overview is gone. Running contracts now count in the row of their product:
- **Customers:** the places a product's contracts reserve are added in blue, for example **2 + 3** for two game server customers and three game server places under contract.
  - Hover over the figure to see the contract places and what those contracts pay per game day.
- **Load:** the bar includes the reserved places.
- **$ / game day:** the contracts' daily pay is added to the product's income.
- **No racks yet:** a product with running contracts but no rack of its own still gets its row, so no contract is left out.

The totals at the top (per hour, per game day, per month) already included contract income and are unchanged. The Customers tab keeps listing each contract as its own row.
