# Data Center AddOn 1.9.16

**Starter kit in Data Center SkyBlock worlds.** Every player now gets Data Center's starter kit, with the Hosting Manager, on their first login to a "Data Center SkyBlock" world.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar) · Jade 15 (for the look-at tooltips) · JEI 19 (for the recipe pages)
Install on the **server and every client**, in exactly the same version.

## Starter kit
- Data Center hands its kit out only by command (`island create`) or when SkyWorlds creates an island. In the add-on's SkyBlock world neither happens, so the add-on hands it out on the first login.
- Each player gets it once; Data Center keeps track of that.
- Data Center's `giveStarterKit` setting still applies: with it off, there is no kit.

## Languages
English and German.
