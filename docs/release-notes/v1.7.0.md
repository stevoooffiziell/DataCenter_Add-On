# Data Center AddOn 1.7.0

The first step of a new customer model: every hosting product now has a **market**, a pool of potential customers that grows with the internet. A new **Market** tab in the Hosting Manager shows it. The 1.7.x releases build the rest of the model on top of it, one piece per release.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar) · Jade 15 (for the look-at tooltips)
Install on the **server and every client**. Server and clients must run exactly the same add-on version; a client with another version is refused when it joins.

## Market pool
- Every product (shared web, mail, reseller, game servers, VPS, colocation) has a pool of potential customers in the whole market.
- **Up to 2008** the pool follows Data Center's own demand of the year: it is 5 times the number of customers Data Center's customer book settles at with 0 reputation.
- **From 2009** Data Center's demand stays flat; the pool now grows on with the number of internet users worldwide (1.75 bn in 2009, 3.1 bn in 2015, 5.6 bn in 2025).
- Examples (mid-year): shared web 3,200 in 1999, 6,100 in 2009, 14,200 in 2015; VPS 600 in 2003, 2,600 in 2009.
- In this release the pool only shows the market. It does not change how many customers you get yet.

## Market tab
A sixth tab in the Hosting Manager:
- The internet users worldwide on the current date.
- One row per product that can be sold today: the market, your customers and your share of the market.
- The tab works without racks and without a cable plugged into the manager.

## Technical
The network version is now the add-on version itself, so any mismatch between server and client is refused at login.
