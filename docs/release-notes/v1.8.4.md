# Data Center AddOn 1.8.4

Part 5 of the new reputation model: **the customer class comes from both values**, Ruf and renown. A class becomes a goal to work for instead of a time to wait.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar) · Jade 15 (for the look-at tooltips)
Install on the **server and every client**, in exactly the same version.

## Classes from Ruf and renown

| Class | Ruf | Renown | Room (as in Data Center) |
|---|---|---|---|
| Hobbyists | – | – | – |
| Small Business | ≥ 80 % | ≥ 100 | – |
| Mid-Market | ≥ 90 % | ≥ 200 | Tier I |
| Enterprise | ≥ 95 % | ≥ 400 | Tier II |
| Finance & Government | ≥ 98 % | ≥ 600 | Tier III |

- Data Center decided the class from the points alone (150 / 350 / 600 / 850).
- **Room certification** stays as in Data Center: a rack only serves the class its room's tier allows.
- **Keeping a class:** once unlocked, a class stays while the Ruf is at most 5 % and the renown at most 25 below its requirement.
- The class is re-checked once a second, so a falling Ruf can cost a class without any change of the points. Data Center's chat message and advancements for a new class stay.
- **When you update**, your class is decided anew. An account with many points but a weak Ruf can drop a class; one with a good Ruf can rise.
- Everything that depends on the class works as before: income multiplier, rack limits, sub-pools of the market (1.7.4), contracts.

## Reputation tab
At the bottom: your class and what the next one needs, e.g. "Next: Mid-Market · Ruf 92 % / 90 % ✔ · Renown 150 / 200 ✘ · Room: Tier I". Hover for all requirements.

## Technical
The add-on replaces the class rule inside Data Center's reputation (`HostingReputation.classFor` in `adjust`). If a Data Center update changes it, Data Center's own classes apply. The game does not crash.
