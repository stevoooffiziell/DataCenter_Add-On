# Data Center AddOn 1.9.14

**Data Center SkyBlock world type.** The SkyBlock starter map is now part of the add-on: choose **"Data Center SkyBlock"** under World Type when creating a world. No datapack needed.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar) · Jade 15 (for the look-at tooltips) · JEI 19 (for the recipe pages)
Install on the **server and every client**, in exactly the same version.

## The world type
- The overworld is a void with a biome of its own, "SkyBlock Island". Monsters and animals spawn as in plains, so mob farms work. The Nether and the End stay as they are.
- On the first start of the world a starter island is placed at 0, 0: an oak, a 7 × 7 server room built from Data Center's dark blocks, and a chest with lava, ice, seeds, building blocks and a German island guide.
- The world spawn is set on the island and the spawn radius to 0, so nobody spawns over the void. The island is placed once per world.
- Every player is greeted once with a hint to the guide. The starter kit with the Hosting Manager comes as usual.
- Normal worlds and the vanilla void preset are not touched.
- Dedicated servers: `level-type=data_center_addon:skyblock` in `server.properties`.

## Technical
`tools/generate-skyblock.py` now writes the island straight into the add-on's resources (`structure/skyblock_island.nbt`) instead of building a datapack.
