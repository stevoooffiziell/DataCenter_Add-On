# Data Center AddOn 1.6.7

Fixes from a code review of everything since 1.5.2: one way to make money from nothing, a network version that did not change, deadlines one day too long, and a few smaller things.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar) · Jade 15 (for the look-at tooltips)
Install on the **server and every client**. Server and clients must run the same version: a client with an older add-on is now refused when it joins.

## Fixes
- **Setup fees and prepayment no longer pay twice.** Before, every rise of a product's customer count counted as new customers. A rack that lost power and filled up again paid all the setup fees again and booked new annual plans with cash up front. Now only customers above the most a product ever had count as new.
- **Version check at login.** The Hosting Manager's network data changed in 1.6.0, but the add-on did not say so. A client on 1.5.x could join a 1.6.x server and was disconnected with a packet error when it opened a manager. Now the server refuses it cleanly at login.
- **Deadlines and offers count today as their first day.**
  - A delivery order with 4 days now runs 4 days, not 5.
  - Delivery offers stay open 3 days, not 4.
  - Hosting contract offers stay open 4 days, not 5.
  - The days shown match.
  - Orders that were already running keep their old deadline.
- **Delivering a GPU server:** when an order wants a server and a GPU server, "Deliver" now fills the GPU server goal first. Before, the GPU server could be used up on the plain server goal, and then the order could not be finished.
- **Prepayment refunds follow real losses.**
  - Customers on an annual plan no longer leave with ordinary churn that new customers fill again.
  - When a product loses more than 2 % of its customers from one in-game day to the next (an outage, a rack removed, a lower fill), the same share of the plans ends and gets its rest back.
  - In any case, there are never more prepaid customers than customers.
- **REVENUE start bonus:** the simpler delivery orders of a young company now end together with the start bonus when it ends at a revenue, instead of after a fixed number of days.
- **No message flood after a time skip.** After the server was down or players slept through several days, every missed day used to open and expire a service ticket, each with two chat messages. Now missed days are settled quietly. New tickets and instalment warnings only come for the current day.
- **Service tickets need the rack.** A ticket now only pays when its rack is still there. Before, right-clicking any block at the rack's old position closed it.
