# Data Center AddOn 1.4.1

A small update for the Hosting Manager: it now tells you when a shared hosting rack earns nothing because of the control panel licence.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar)
Install on the **server and every client**.

## Hosting Manager: panel licence warning
Data Center bills every server of a shared hosting rack separately: what its customers pay, minus **$30 a month for the control panel licence** (with software enabled, for every shared offer except game servers). A result below zero is cut to $0. A rack whose customers are spread over too many servers therefore shows customers but **$0 / day**, without saying why.

The Hosting Manager now points this out:
- **Overview:** a warning below the network bar names how many shared racks earn nothing because of the licence, and what to do about it.
- **Racks tab:** the status of such a rack reads **"Licence > income"** instead of "OK". Select the rack to see the hint "Too few customers per server to cover the panel licence".

What helps: fewer servers in the rack (customers are split over the servers by their capacity, so fewer servers means more customers each), waiting until more customers sign up, or using the spare servers for dedicated servers. Lowering the fill does not help, because it shrinks every server alike.

## Languages
English and German.

## Known limitations
- The warning only shows when a whole rack earns $0. If some of its servers cover the licence and others do not, the rack earns something and is not flagged.
