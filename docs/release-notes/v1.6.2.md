# Data Center AddOn 1.6.2

The Hosting Manager now shows its income in the same unit as the Hosting Rack, and it includes the start bonus.

**Requires:** Minecraft 1.21.1 · NeoForge 21.1 · Data Center 2.1.3 or newer
**Optional:** FTB Quests (for the guide and the calendar) · Jade 15 (for the look-at tooltips)
Install on the **server and every client**.

## Clear time units
Before this version, the Hosting Rack's "Rate: $/h" meant a **real hour**, while the Hosting Manager's "/ day" meant an **in-game day**. In-game days are short, so the manager's figures looked tiny.
- With 24 in-game days per Minecraft day, an in-game day lasts 50 seconds and an hour holds 72 of them.
- So $91.88/h in the rack is the same income as $1.27 a day in the manager.

## Overview
- **Five cards:**
  - **Customers**
  - **$ / hour**: a real hour, the same figure as "Rate" in the Hosting Rack
  - **$ / game day**
  - **$ / month**: an in-game month
  - **Racks**
- **Hover** over an income card for a short explanation of the units.
- **Start bonus included:** the income cards include the start bonus while it runs. A green line below the cards shows its share, for example "incl. start bonus +200 %: +$183.76 per hour (+$2.55 per game day)".

## Labels
The "$ / day" columns in the Overview, Customers and Racks tabs, and the Jade tooltips of the Hosting Manager and the Hosting Rack, now say **"$ / game day"**. They do not include the start bonus. Contracts are paid per in-game day, so the tables keep that unit.
